## Файли
- `index.html` — лендінг (самодостатній файл, шрифти й зображення вбудовані)
- `.nojekyll` — щоб GitHub Pages віддавав файли як є

## Публікація на GitHub Pages
1. Створи репозиторій на github.com (наприклад, `mastermind`), тип Public.
2. Add file → Upload files → перетягни файли з цієї папки → Commit changes.
3. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
4. За 1–2 хв сайт буде за адресою `https://<логін>.github.io/mastermind/`.
